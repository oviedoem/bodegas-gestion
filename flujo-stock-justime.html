Cómo se mueven Disponible, Físico y Pedido en cada ciclo de documento
Columna
Disponible
Stock neto real. Lo que se puede vender ahora mismo.
Físico − Compromisos
Columna
Físico
Cantidad real presente en la bodega. Solo cambia con despacho o recepción física.
Columna
Pedido
Suma de ventas comprometidas pendientes de despacho o boleta.
Ciclo 1 — Venta con boleta o factura
C1
Venta Mesón / Nota de Venta → Boleta o Factura → Guía de Despacho
Ciclo completo de una venta regular. Tres pasos, tres actores.
VMN / NVM
Venta Mesón / Nota de Venta
👤 Vendedor
El vendedor registra la venta. El sistema compromete el stock al instante.
Disp ↓ Fís sin cambio Ped ↑
Documento hijo — no se puede anular mientras tenga padre. La diferencia Dif = Fís − Disp queda abierta aquí.
BVE / FVE
Boleta / Factura de Venta
💳 Cajera
El cliente pasa por caja. La cajera emite el documento tributario. El VMN pasa a ser documento hijo de esta BVE/FVE.
Disp sin cambio Fís sin cambio Ped ↓
Dif aún abierta. El stock físico no bajó todavía — la guía de despacho está pendiente. El panel Dif SV marca ⭐ a este documento.
GME / GDV
Guía de Despacho / Egreso
📦 Bodega
El producto sale físicamente de la bodega. Recién aquí el Físico baja y la diferencia desaparece.
Disp sin cambio Fís ↓ Ped sin cambio
✓ Ciclo completo — Dif = 0
Ciclo 2 — Cliente no pasa por caja
C2
Venta Mesón sin boleta → Anulación del VMN
El cliente se va sin pagar. No hay documento tributario — el VMN es padre y se puede anular directamente.
VMN / NVM
Venta Mesón / Nota de Venta
👤 Vendedor
El vendedor registra la venta. El stock queda comprometido.
Disp ↓ Fís sin cambio Ped ↑
Aquí el VMN es padre — sin BVE/FVE creada todavía.
ANULAR VMN
Anulación de Venta Mesón
👤 Vendedor / Supervisor
Al no ser documento tributario, el VMN se puede anular directamente. Libera el stock comprometido.
Disp ↑ Fís sin cambio Ped ↓
✓ Ciclo completo — Dif = 0
Ciclo 3 — Devolución de cliente
C3
Guía de Devolución → Nota de Crédito
El cliente devuelve o cambia un producto. Flujo inverso a la venta.
GDC
Guía Devolución Cliente
👤 Vendedor
El vendedor registra la devolución. El stock disponible sube anticipadamente, pero el físico no — el producto aún no fue recepcionado en bodega.
Disp ↑ Fís sin cambio Ped sin cambio
Dif negativa (Disp > Fís). Mismo síntoma visual que Anomalía JT — pero la causa y la acción son distintas. El panel muestra fila roja. La acción correcta es emitir la Nota de Crédito en caja, no ir a JustWeb a Editar+Grabar.
NCE
Nota de Crédito
💳 Cajera
La cajera emite la nota de crédito. El sistema baja automáticamente la GDC del menú "Por Recepcionar" y suma el físico.
Disp sin cambio Fís ↑ Ped sin cambio
✓ Ciclo completo — Dif = 0
Ciclo 4 — Traslado entre bodegas / sucursales (Anomalía JT)
C4
GRT / GIB — Guía de Traslado sin segundo paso
La guía se emite en origen pero no se confirma en destino. El sistema queda a medias.
GRT / GIB
Guía Recepción Traslado / Ingreso Entre Bodegas
👤 Usuario Origen
Se emite la guía en la bodega de origen. Disp baja en origen. En destino el producto aparece "Por recepcionar".
Disp origen ↓ Fís destino sin cambio
Anomalía JT activa. Disp > Fís en destino hasta que se complete el segundo paso.
Editar + Grabar
Confirmación en JustWeb
👤 Usuario Destino
El usuario de destino va a "Mantención de Despachos", abre la guía, presiona Editar y luego Grabar. Eso confirma que el producto llegó físicamente.
Fís destino ↑
✓ Ciclo completo — Dif = 0
Comportamiento según permisos de usuario

⚠️ Permisos limitados de bodega

La guía emitida queda en estado "Por recepcionar". El usuario de destino debe entrar al menú, abrir el documento, presionar Editar y luego Grabar para que el físico suba en la bodega de destino.

✓ Permisos completos

Al emitir la guía, el sistema suma Disponible y Físico al mismo tiempo en ambas bodegas. No requiere el paso Editar+Grabar — el ciclo se completa solo.

Ciclo 5 — Recepción de compra (OC → GRC)
C5
OC / GRC / GRS — Orden de Compra y Guía de Recepción
El proveedor entrega mercadería. La recepción sube el stock según los permisos del usuario que recepciona.
OC / OCL / OCE
Orden de Compra
👤 Compras / Administración
Se emite la OC al proveedor. El ERP reserva las unidades en Tránsito — el producto "viene en camino" pero aún no está en bodega.
Tránsito ↑ Disp sin cambio Fís sin cambio
GRC / GRS
Guía de Recepción de Compra / Servicio
👤 Bodeguero / Recepcionista
Llega la mercadería. El bodeguero crea la GRC vinculada a la OC. El comportamiento siguiente depende de los permisos del usuario.
Tránsito ↓
Comportamiento según permisos del usuario que recepciona

⚠️ Permisos limitados

Al crear la GRC, solo sube el Disponible. El Físico no sube de inmediato. El usuario debe entrar a "Mantención de Despachos" en JustWeb, abrir la GRC, presionar Editar y luego Grabar para que el Físico también suba.

Disp ↑ (inmediato) Fís sin cambio hasta Editar+Grabar
Dif < 0 activa mientras no se complete el segundo paso — Disp superó al Fís.

✓ Permisos completos

Al grabar la GRC, el ERP sube Disponible y Físico al mismo tiempo, y baja el Tránsito. El ciclo queda cerrado en un solo paso, sin intervención adicional.

Disp ↑ Fís ↑ Tránsito ↓
✓ Ciclo completo — Dif = 0
Ciclo 6 — Venta Calzada (stock negativo permitido)
C6
BVE (Disp negativo) → GRT/GIB ingreso → GME despacho
Bodega Calzada acepta ventas con stock negativo. El producto llega desde otra sucursal o CD después de facturar.
BVE / FVE Boleta o Factura Electrónica
Disp ↓ Fís sin cambio
El vendedor cierra la venta y emite el documento tributario. Disp puede quedar negativo — la bodega está configurada para permitirlo. El producto aún no existe físicamente en Calzada.
📊 Estado: Dif > 0 — Físico = 0, Disp < 0 (negativo). El sistema muestra diferencia hasta que llegue el producto.
GRT / GIB Guía Recepción Traslado / Guía Ingreso Bodega
Disp ↑ Fís ↑
El producto llega desde otra sucursal o CD. El GRT (entre bodegas) o GRC (desde proveedor) registra el ingreso: Disp sube compensando el negativo y queda en 0; Físico sube al total recibido.
📊 Estado: Dif = cantidad recibida — Disp = 0, Físico > 0. El producto está en bodega pero la guía de despacho aún no se emitió.
GME Guía de Despacho
Disp sin cambio Fís ↓
El producto sale físicamente de la bodega hacia el cliente. Recién aquí el Físico baja. El ciclo se cierra: Disp = 0, Físico = 0.
✓ Ciclo completo — Dif = 0
⚠ Dif positiva ≠ error: Si ves Dif > 0 en Calzada con BVE reciente y GRT de ingreso, es el ciclo normal en espera de la GME de despacho. No requiere corrección en el ERP — solo emitir la guía cuando el producto salga al cliente.

Dif = Físico − Disponible. Dif > 0 (normal): hay compromiso abierto — venta emitida sin despacho físico. Dif < 0 (anomalía): Disp superó al Fís — puede ser GRT sin 2° paso, GDC sin Nota de Crédito, o GRC con permisos limitados sin confirmar. Verificar el tipo de documento antes de actuar.
